## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Unicode-aware regular expressions for Mojo, built for the pre-tokenizers of LLM
tokenizers (GPT-2, Llama 3, Qwen, DeepSeek, gpt-oss, Spark-X2.5) and checked
against Python's `regex` by differential testing. Pure Mojo, CPU. Build with
`-I src`; requires Mojo 1.2.

## Highlights

- `$` matches before a final newline like Python, and `\Z` and `\z` are supported.
- Patterns Python rejects now raise: `{m,n}` with `n` below `m`, `\1`..`\9` and `\k<name>` backreferences, a trailing `\p`.
- A pattern such as `a{99999999999}` raises in milliseconds: the compiled program size is capped.

## Changes

### Added
- `$` before a final newline, `\Z` and `\z`.
- The `mojo-uregex` skill, `docs/api.md`, `docs/design.md` and `scripts/ci.sh`.

### Changed

- README: one install block, one example; the gate runs `examples/quickstart.mojo`.
### Fixed
- A trailing `\p` raises instead of aborting the process.
- `{m,n}` with `n` below `m` is rejected.
- `\1`..`\9` and `\k<name>` are rejected, as backreferences are unsupported.
- The CI workflow file parsed as invalid YAML; the `uv sync` step is quoted.
### Removed
- The unused `to_codepoints`.
