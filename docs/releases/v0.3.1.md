## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.

Unicode-aware regular expressions for Mojo, built for the pre-tokenizers of LLM
tokenizers (GPT-2, Llama 3, Qwen, DeepSeek, gpt-oss, Spark-X2.5) and checked
against Python's `regex` by differential testing. Pure Mojo, CPU. Build with
`-I src`; requires Mojo 1.2.

## Highlights

- Builds and runs on the stable Mojo 1.2.0 release.

## Changes

### Changed
- The pin moves to Mojo 1.2.0 (`pyproject.toml`); README says Mojo 1.2.
### Fixed
- The library did not build on Mojo 1.2.0: `String(StringSlice(unsafe_from_utf8=...))` sends the compiler into a recursion. It now uses `String(unsafe_from_utf8=...)`, which builds on 1.1 and 1.2.
